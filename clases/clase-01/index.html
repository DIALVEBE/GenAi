Where is the intelligence?

An alarm set for 6:00 a.m. follows a fixed instruction. A traffic light that adapts to vehicle flow uses information from the environment. A system that estimates academic risk from historical records learns a pattern from data.

In engineering, intelligence is evaluated through observable capabilities: perceiving information, representing a problem, reasoning about alternatives, learning from experience, making decisions, and acting toward an objective.

A system is not intelligent because it looks human. It is evaluated by the quality of its decisions within an objective and a context.

A practical definition of AI

An AI system is machine-based. It receives inputs, uses explicit or implicit objectives, infers how to produce outputs, and can influence physical or virtual environments through predictions, content, recommendations, or decisions.

Automation is not automatically AI. A fixed macro can copy data without learning. AI appears when the system includes perception, reasoning, search, learning, or decision mechanisms beyond a rigid sequence of instructions.

InputsData, signals, images, text, measurements, or states.
ObjectivesCriteria that orient behavior.
InferenceTransformation from input to estimate, class, recommendation, or action.
InfluenceThe output can guide a person or affect an environment.
03 / 10

Rules programmed vs. patterns learned

In traditional programming, the rule is written by the developer. In Machine Learning, examples, a task, and a performance measure are supplied so an algorithm can adjust a model.

Code does not disappear. It collects data, prepares it, selects algorithms, trains models, calculates metrics, and integrates predictions into applications. What changes is the origin of the decision function.

04 / 10

AI, Machine Learning, and Deep Learning

Artificial Intelligence is the broad field. Machine Learning is a subfield focused on improving behavior through data or experience. Deep Learning is a family of Machine Learning methods based on neural networks with many layers.

This hierarchy avoids three common mistakes: not all AI uses ML, not all ML uses deep networks, and not every practical problem needs a neural network.

Artificial Intelligence Perceive, reason, plan, decide, and learn.
Machine Learning Models adjusted with data.
Deep Learning Neural networks with multiple layers.
05 / 10

What does it mean for a machine to learn?

A program learns from experience when its performance on a task improves according to a defined measure. This forces three questions: what task should the system perform, what experience does it learn from, and how will improvement be measured?

Learning does not mean understanding like a person. A model can capture a statistical regularity without knowing its cause.

ElementQuestionAcademic example
TaskWhat should the system do?Classify whether a student is at risk.
ExperienceWhat information does it learn from?Historical attendance, grades, and final outcome.
PerformanceHow do we decide it improved?Recall, precision, and review of false alerts.

The basic language of data

A dataset is a structured collection of examples. In a table, each row usually represents an observation and each column represents a variable.

Features are the input variables used by the model. The label, objective, or target is the value to predict in supervised learning.

Three ways to learn

Machine Learning paradigms differ by the signal available to adjust behavior. Supervised learning has known answers, unsupervised learning searches for structure, and reinforcement learning uses accumulated consequences.

Data + labelSupervised

Learns from examples that include the correct answer.

Classification, regression
Only dataUnsupervised

Finds structure without a predefined answer.

Clustering, anomaly detection
ExperienceReinforcement

Acts, receives rewards or penalties, and learns a policy.

Agent, action, reward

The life cycle of a model

A Machine Learning project does not start by selecting an algorithm. It starts by defining a decision and continues after the model is used.

A valuable model is not simply the one with the highest number in a lab. It is the one that improves a real decision without creating unacceptable harm.

09 / 10

Training, validation, testing, and metrics

Evaluating with the same data used for training gives an optimistic view. Training adjusts parameters, validation compares configurations, and testing estimates final performance once design decisions are closed.

Metrics must match the impact of the decision. In academic risk, missing a real case can be more costly than creating an extra alert.

AccuracyOverall proportion of correct predictions.
PrecisionOf all alerts, how many were real?
RecallOf all real risk cases, how many were detected?
MAEAverage absolute error for numeric predictions.
10 / 10

Generalization and responsible decisions

Generalizing means applying a learned pattern to new cases from the same problem. Underfitting is too simple, overfitting memorizes noise, and good fit captures the pattern that remains useful outside training data.

A prediction is evidence for a decision, not an automatic sentence. Responsible use combines technical quality, human review, privacy, transparency, and institutional accountability.

UnderfittingToo simple
Good fitCaptures the pattern
OverfittingMemorizes noise

Mini lab

From dataset to prediction

This artificial example shows the flow of a supervised classification task. It is useful for learning the vocabulary, but it is not evidence for a real academic decision.

  1. Create a small dataset.
  2. Separate features and target.
  3. Split training and test data.
  4. Train a decision tree.
  5. Evaluate and predict a new case.
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score, confusion_matrix

df = pd.DataFrame({
    "attendance": [95, 60, 82, 55, 90, 72, 88, 64],
    "tasks": [10, 4, 8, 5, 9, 6, 9, 5],
    "first_grade": [4.2, 2.3, 3.5, 2.8, 4.0, 3.0, 3.9, 2.7],
    "passed": [1, 0, 1, 0, 1, 0, 1, 0],
})

X = df[["attendance", "tasks", "first_grade"]]
y = df["passed"]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

model = DecisionTreeClassifier(max_depth=3, random_state=42)
model.fit(X_train, y_train)

predictions = model.predict(X_test)
print("Accuracy:", accuracy_score(y_test, predictions))
print(confusion_matrix(y_test, predictions))
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score, confusion_matrix

df = pd.DataFrame({
    "asistencia": [95, 60, 82, 55, 90, 72, 88, 64],
    "tareas": [10, 4, 8, 5, 9, 6, 9, 5],
    "primer_corte": [4.2, 2.3, 3.5, 2.8, 4.0, 3.0, 3.9, 2.7],
    "aprobo": [1, 0, 1, 0, 1, 0, 1, 0],
})

X = df[["asistencia", "tareas", "primer_corte"]]
y = df["aprobo"]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)

modelo = DecisionTreeClassifier(max_depth=3, random_state=42)
modelo.fit(X_train, y_train)

predicciones = modelo.predict(X_test)
print("Accuracy:", accuracy_score(y_test, predicciones))
print(confusion_matrix(y_test, predicciones))
